# TSPEC-P04 — ComponentPass (Work Order)

> Same harness/conventions as **TSPEC-P02 (read it first)** + ADR-0016. COLLISION-FREE:
> only your pass file + test. Heuristic below is the architect's decision; apply it exactly.

- **TSPEC:** TSPEC-P04 · **Owner:** ROLE_IMPLEMENTER · **Depends on:** TSPEC-A006, TSPEC-I006, ADR-0016 (COMPLETE) · **Wave:** 5

## Objective
Detect frontend components from symbols and add `COMPONENT` nodes, so closure can see the
`COMPONENT` execution stage. Heuristic and deterministic.

## Files (ADDITIVE ONLY)
- create `packages/passes/src/ComponentPass.ts`
- create `tests/passes/component-pass.test.ts`

## Behavior
`name = "ComponentPass"`, `priority = PASS_PRIORITY.ComponentPass`, `supports()` true.
`run(ctx, draft)`: for each `pr` whose `artifact.path` ends with `.tsx` or `.jsx`, for each
`sym` in `pr.symbols`:
- if `sym.kind` is `function` or `class`, and `sym.name` is PascalCase (first character is an
  uppercase letter), create a `COMPONENT` node: id = `makeId("component", sym.name)`,
  name = `sym.name`, language = `pr.artifact.language`, artifactId = `pr.artifact.id`,
  span = `sym.span`, hash = "0", default execution, evidence `[AST]`.
- otherwise skip. (Only `.tsx`/`.jsx` files; lowercase-named functions are not components.)

Idempotent (replace by id).

## Acceptance (each a test; DefaultIRDraft + CompilationContext stub)
1. a `function LoginForm()` symbol in a `.tsx` artifact → a `COMPONENT` node named `LoginForm`.
2. a lowercase `function helper()` in a `.tsx` artifact → no component node.
3. a PascalCase symbol in a `.ts` (non-tsx) artifact → no component node.
4. determinism: two runs yield equal sealed IR.
5. coverage ≥ 95%.

## Forbidden
Edit no shared file/roster/`@rir/core`/adapter. Do NOT change the heuristic. Package-name imports only.

## References
ADR-0016; `@rir/ir` (`NodeKind.Component`); `@rir/closure` (`STAGE_OF_NODE_KIND` maps COMPONENT→COMPONENT stage); DefaultIRDraft.

# TSPEC-P05 — SQLPass (Work Order)

> Same harness/conventions as **TSPEC-P02 (read it first)** + ADR-0016. COLLISION-FREE:
> only your pass file + test. Do NOT edit `packages/passes/src/index.ts`. Package-name imports.
> The detection heuristic below is the architect's decision (amends ADR-0016); apply it exactly.

- **TSPEC:** TSPEC-P05 · **Owner:** ROLE_IMPLEMENTER · **Depends on:** TSPEC-A006, TSPEC-I006, ADR-0016 (COMPLETE) · **Wave:** 5

## Objective
Detect database access from call facts and add `SQL_QUERY` nodes + edges, so closure can
see the `DATABASE` stage. Heuristic and deterministic.

## Files (ADDITIVE ONLY)
- create `packages/passes/src/SQLPass.ts`
- create `tests/passes/sql-pass.test.ts`

## Behavior
`name = "SQLPass"`, `priority = PASS_PRIORITY.SQLPass`, `supports()` true. `run(ctx, draft)`:
for each `pr` in `ctx.parseResults ?? []`, for each `call` in `pr.calls`:
- let `method` = the last `.`-segment of `call.callee`. If `method` (lower-cased) is in the
  fixed set `{ query, execute, exec, raw, insert, update, delete, find, findone, save }`:
  - create a `SQL_QUERY` node: id = `makeId("sql", pr.artifact.path, String(call.span.startLine))`,
    name = `method`, language = `pr.artifact.language`, artifactId = `pr.artifact.id`,
    span = `call.span`, hash = "0", default execution, evidence `[AST]`.
  - if `call.enclosing` resolves to an existing node (`draft.getNode(makeId("decl", call.enclosing))`),
    add an edge from it to the SQL node: kind `WRITES` if `method` ∈ `{ insert, update, delete, save, exec, execute }`, else `READS`. id = `makeId("edge","sql", from, sqlId)`, evidence `[AST]`.
- otherwise no node/edge. (`SQL_QUERY` maps to the `DATABASE` execution stage in closure.)

## Acceptance (each a test; DefaultIRDraft + CompilationContext stub)
1. a call `this.db.query(...)` (enclosing a known decl) yields a `SQL_QUERY` node and a `READS` edge.
2. `this.db.insert(...)` yields a `WRITES` edge.
3. a non-DB call (e.g. `foo.bar()`) yields no SQL node.
4. determinism: two runs yield equal sealed IR.
5. coverage ≥ 95%.

## Forbidden
Edit no shared file/roster/`@rir/core`/adapter. Do NOT change the method set. Package-name imports only.

## References
ADR-0016; `@rir/ir` (`NodeKind.SqlQuery`); `@rir/closure` (`STAGE_OF_NODE_KIND` maps SQL_QUERY→DATABASE); DefaultIRDraft.

# TSPEC-P15 — GitPass (Work Order)

> Same harness/conventions as **TSPEC-P02 (read it first)** + ADR-0016. COLLISION-FREE:
> only your pass file + test. Not added to the default pipeline by you — the architect
> wires it. Package-name imports.

- **TSPEC:** TSPEC-P15 · **Owner:** ROLE_IMPLEMENTER · **Depends on:** TSPEC-A006, TSPEC-I006, ADR-0016 (COMPLETE) · **Wave:** 5

## Objective
Attach `GIT` provenance evidence to nodes from the git history of their source file.
Deterministic given the injected git runner; testable without a real git repo.

## Files (ADDITIVE ONLY)
- create `packages/passes/src/GitPass.ts`
- create `tests/passes/git-pass.test.ts`

## Behavior
`name = "GitPass"`, `priority = PASS_PRIORITY.GitPass`, `supports()` true. Constructor takes
an injectable runner so it is testable:
```ts
type GitRunner = (filePath: string) => string | null; // returns last-commit sha or null
constructor(private readonly runGit: GitRunner = defaultRunner) {}
```
`defaultRunner(path)` runs `git log -1 --format=%H -- <path>` via `node:child_process`
`execFileSync` (cwd = the file's directory), returning the trimmed sha or `null` on error.

`run(ctx, draft)`:
- build a map `artifactId → path` from `ctx.artifacts`.
- for each `node` in `draft.getNodes()` with a known `artifactId`, call `this.runGit(path)`.
  If it returns a sha, re-add the node with an extra evidence entry
  `{ source: "GIT", locator: sha, confidence: 1 }` (do not duplicate an identical entry).
- nodes whose file has no sha are unchanged. Idempotent.

## Acceptance (each a test; DefaultIRDraft + CompilationContext stub)
1. with an injected runner returning `"abc123"`, a node gets a `GIT` evidence entry with `locator === "abc123"`.
2. with a runner returning `null`, the node's evidence is unchanged.
3. re-running does not duplicate the GIT evidence.
4. determinism: two runs with the same runner yield equal sealed IR.
5. coverage ≥ 95%.

## Forbidden
Edit no shared file/roster/`@rir/core`/adapter. Do NOT add GitPass to any builder. Package-name imports only.

## References
ADR-0016; `@rir/ir` (`EvidenceSource.Git`); `node:child_process` `execFileSync`; DefaultIRDraft.
